# SK Store - Digital App Selling Website

Simple, clean website to sell your Android app for ₹49.

## Features
- Beautiful product page
- Brown "Buy Now" button
- Direct UPI / Bank payment
- Customer submits payment proof
- Admin panel to approve orders & give download
- Upload APK + Screenshots easily

## How to Run Locally
```bash
node server.js
```
Open: http://localhost:3000

Admin: http://localhost:3000/admin  
Password: `skstore2026`

## How to Deploy (Free)
1. Create free account on **Render.com** or **Railway.app**
2. Upload this folder or connect GitHub
3. Start command: `node server.js`
4. Done!

## First Steps After Deploy
1. Go to /admin
2. Login with password
3. Fill your real UPI ID, Bank details
4. Upload your APK file
5. Upload screenshots
6. Save

Then share the main link with customers.
